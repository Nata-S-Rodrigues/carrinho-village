CARRINHO VILLAGE — APP DE LEMBRETES
=====================================

1. Abra o index.html em um navegador para testar a interface.
2. O app consulta a API de lembretes já existente.
3. "Abrir WhatsApp" abre o WhatsApp com o número e a mensagem preenchida.
4. O envio é MANUAL: você revisa e toca em Enviar.
5. A API usada é a existente do Google Apps Script; este pacote não usa a API paga do WhatsApp para enviar mensagens.
